# Seytro: Elevating Hospitality

Bygg en modern hemsida för Seytro — en AI-driven operationsplattform för restauranger och hotell. Ta designinspiration från https://www.elyrasystems.com/ (hero med fullskärmsbild, stor rubrik, ren struktur, minimal navigation) men använd Seytros egen färgpalett: mörk skogsgrön (#1F4E3D) och vitt istället för Elyras mörka bordeaux. Strukturera runt tre pelare: Gästkommunikation (röstagent, e-postconcierge, bokningsassistent), Restaurangdrift (bordsplacering, salsplan, tillgänglighet) och Gästtillväxt (gästinsikt, analys, kampanjer). Inkludera en hero-sektion med tydligt värdeerbjudande, en sektion om vision/framtid, och en tydlig CTA för att boka demo.
